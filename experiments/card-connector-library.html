System rules

the surgical contract
1 · State is inversion: anything alive/active/selected is ink-on-bone flipped.
2 · Liveness is one pulsing dot. No other ambient motion.
3 · Hierarchy is size + spacing only. No weight, no color.
4 · chip = state · tag = meta · pill = action. Never interchangeable.
5 · Every board: top zone (identity + 4-stat strip) / middle / bottom (≤3 pills + tabbar).
6 · m-row is the only list pattern. m-kv is the only spec pattern.
7 · Modals are flat sheets. Disclosure beats navigation (L0→L1→L2 before any sheet).
8 · Rarity is typographic: dashed BRK, inverted MIL, double-ring MYTH.
9 · Nothing exists that doesn't answer a line in docs 01–07.
