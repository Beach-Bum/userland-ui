Card Shapes

Six shape modifiers from a fixed vocabulary. Each shape identifies interaction type. (doc 09)

BITE-TOP

Modals, inspector panels, premium surfaces. The signature Userland shape.

TAB-TOP

Causal chains: rig slots, run→reward→item sequences. "This follows from that."

TICKET + PERF
RARE

Tradeable items, market listings, run entry passes.

SN: JDN-0482-LENS · GHOST LENS
UNDERPLATE

Premium/high-rarity items. Depth layer behind card in rarity color. LEG shown here.

NOTCH-SIDE

Rig components. Punch-card notches = "this plugs into a system."

Inline Inspector
