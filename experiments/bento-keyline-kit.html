USERLAND · KIT-B
“BENTO KEYLINE”

A UI-kit experiment: the bento / keyline / pill visual system from the four reference shots, rebuilt with exact measurements and populated with real Userland game content (six boards, rig slots, 96-item catalogue, SEN/HEAT economy). Phone canonical, scales to pad and desktop.

⚠ EXPERIMENT — NOT PRODUCTION. Owner-directed test (2026-06-11). This file deliberately departs from the locked .dk rails (radius-0, 8×14 cell grid, all-caps mono, decode transitions). The production game UI remains .dk per DIRECTION-OVERRIDE-2026-06-10. Conflict recorded; do not port any of this into the app without owner sign-off.

01 · Foundations

Base unit 4px (2px half-steps for gutters). Cards are flat — separation is the thin shell gap; the 3px-offset keyline lives on controls and the desktop frame only, so lines can never collide. Surfaces use a very small radius — r8 cards/rows/bubbles, 6 nested, 10 bars, 12 frame — with shape options: sci-fi bite corner, 45° cuts, interlock tab, centered pinch, ticket tear — every sculpted junction is a single-path inline SVG (no gradient fringes, no element seams). Controls and indicators stay pill/circle. Gutters 6 (phone) / 8 (desk). Inter / neo-grotesque, tabular numerals everywhere.

06 · Rules & conflict record

Three-zone contract

Every screen: TOP = identity + resources + heat + timers (header card + tag strip). MIDDLE = the one object/list/map being inspected. BOTTOM = action bar (≤3 verbs) above the board tab bar. One recommended next action per screen, always.

Breakpoints

Phone 390 logical is canonical — single column stack, gutter 6. Pad ≥768: two-column bento, gutter 8. Desk ≥1100: 12-column bento in the black keyline frame; a right-side detail rail may appear, but core play never requires it.

Motion

Category controls motion type (CORE bloom · LENS sweep · PORT handshake · BUS route · ICE blade · SKIN shimmer · CACHE seal-crack · MIL threat-lock). Rarity controls color and intensity. Subtle in lists, stronger in detail, strongest in decode/cache reveal. MYTH is the shimmer tier; BRK flickers. Everything sits behind prefers-reduced-motion plus the in-app Motion setting.

Color is never alone

Rarity text pill always accompanies rarity color (BRK/COM/TUN/RARE/LEG/EPIC/MIL/MYTH). MIL replaces ILLEGAL everywhere and must read as red. High-contrast theme keeps ink-on-paper with rarity pills intact.

3D library slot

The device-card stage (r16 inner surface) is the mount point for the production 3D device renders. The glyph rigs here are stand-ins only — this file does not touch the model library or its hooks.

Conflict record — read before porting

This kit contradicts the locked master-plan rails: small radii (8) and round pill controls instead of radius-0/1px borders, free bento composition instead of the 8×14 terminal cell grid, sentence case instead of all-caps, grotesk instead of mono — though the thin 6px shell gutters, sci-fi bite corners, and 45° cut options pull it toward the deck's chamfer language. The six-board order, server-authoritative rule, rarity ladder (MIL not ILLEGAL), catalogue names, and reduced-motion rule are all preserved.
